# D1.3 metadata view as DCAT serialised as JSON-LD (from Zenodo)

The Zenodo folder has a verbatim mapping to DCAT serialised as JSON-LD 1.1 repecting folder structure, etc.
This may be the reference to any item within the uploaed deliverable (D1.3).

The files follow a SPDX relative to package file path.
Each file can be identified by its MD5 hash digest.
